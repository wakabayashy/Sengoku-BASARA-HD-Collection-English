# Sengoku BASARA HD Collection — PlayStation 3 English Translation

An English translation and editing project for **Sengoku BASARA HD Collection** on **PlayStation 3**.

> **Current status: Translation and editing in progress.**

## About the Project

This project aims to make Sengoku BASARA HD Collection accessible to English-speaking players through an English fan translation.

The project is currently in the translation and editing phase. Work is ongoing, and no completion percentage or public release date is being announced at this stage.

## Current Work

The work is focused on translating and editing the game's content and preparing the English material for integration into the PlayStation 3 release.

The project aims to provide readable English text while preserving the original presentation and behaviour of the collection.

Current work includes:

- English translation of game content.
- Text editing and consistency checks.
- Preparation of translated material for integration.
- Review of text presentation and display.
- Further corrections as the project progresses.
